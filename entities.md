# 🗂 Сущности системы

## User

Пользователь приложения. Читатель, библиотекарь или администратор приложения.

### Поля

| Поле        | Тип           | Обязательное | Описание                         |
|-------------|---------------|--------------|----------------------------------|
| id          | INTEGER       | Да           | Уникальный идентификатор (PK)    |
| name        | VARCHAR(25)  | Да           | Имя пользователя        |
| password_hash | VARCHAR(255)   | Да           | Хэш пароля        |
| phone  | VARCHAR(10)     | Да           | Номер телефона пользователя              |
| role     | INTEGER       | Да           | Роль пользователя, по умолчанию reader FK -> Roles.id |
| email     | VARCHAR(255)      | Да           | Почта пользователя, уникальная      |

## Roles

Роли пользователей.

### Поля

| Поле        | Тип           | Обязательное | Описание                         |
|-------------|---------------|--------------|----------------------------------|
| id          | INTEGER       | Да           | Уникальный идентификатор (PK)    |
| title | VARCHAR(8) | Да | Название роли (reader, librarian, admin) |

## Library

Библиотеки, создают свой каталог, книги из которого выдаются читателям.

### Поля

| Поле        | Тип           | Обязательное | Описание                         |
|-------------|---------------|--------------|----------------------------------|
| id          | INTEGER       | Да           | Уникальный идентификатор (PK)    |
| phone | VARCHAR(10) | Да | Телефон библиотеки |
| coordinates | JSONB | Да | Координаты библиотеки {[61.677990, 50.834559]} |
| schedule | JSONB | Нет | Расписание библиотеки |

## Book

Сущность книги.

### Поля

| Поле        | Тип           | Обязательное | Описание                         |
|-------------|---------------|--------------|----------------------------------|
| id | INTEGER | Да | Уникальный идентификатор (PK) |
| library_id | INTEGER | Да | FK -> Library.id |
| isbn | VARCHAR(13) | Да | Международный стандартный книжный номер |
| title | VARCHAR(255) | Да | Название книги |
| author | VARCHAR(255) | Да | Автор книги |
| summary | TEXT | Да | Аннотация книги |
| year_published | INTEGER | Да | Год публикации книги |
| format | VARCHAR(5) | Да | Формат книги |
| amount | INTEGER | Да | Количество копий |
| license | VARCHAR(255) | Нет | Лицензия книги |

## Library_cards

Читательские билеты для регистрации пользователей.

### Поля

| Поле        | Тип           | Обязательное | Описание                         |
|-------------|---------------|--------------|----------------------------------|
| id | INTEGER | Да | Уникальный идентификатор (PK) |
| library_id | INTEGER | Да | FK -> Library.id |
| code | VARCHAR(255) | Да | Номер читательского билета |
| used | BOOLEAN | Да | Билет был использован для регистрации, по умолчанию false |

## Hold

### Поля

| Поле        | Тип           | Обязательное | Описание                         |
|-------------|---------------|--------------|----------------------------------|
| id | INTEGER | Да | Уникальный идентификатор (PK) |
| user_id | INTEGER | Да | FK -> User.id |
| library_id | INTEGER | Да | FK -> Library.id |
| book_id | INTEGER | Да | FK -> Book.id |
| date_created | DATE | Да | Дата, когда пользователь встал в очередь |

### Поля

| Поле        | Тип           | Обязательное | Описание                         |
|-------------|---------------|--------------|----------------------------------|
| id | INTEGER | Да | Уникальный идентификатор (PK) |
| user_id | INTEGER | Да | FK -> User.id |

## Вопросы для самопроверки

1. Почему важно указывать WHERE в UPDATE и DELETE?

Чтобы редактировать/удалять только нужные данные.

2. Что такое первичный ключ (PRIMARY KEY)? Зачем он нужен?

Это столбец в БД с уникальными значениями, он нужен для точной идентификации записи в таблице.

3. Приведите пример, когда VARCHAR(20) лучше чем TEXT, и наоборот.

Для хранения номера телефона лучше подойдет VARCHAR, т.к. его длина заранее известна и довольно мала. Для хранения аннотации книги лучше подойдет TEXT, т.к. аннотация может быть довольно длинной и её длина будет различаться у каждой книги.
